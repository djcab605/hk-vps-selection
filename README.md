## 香港VPS的"便宜"分三种，先认清自己买的是哪种

同样是二三十块一个月，香港机房的方案其实分成完全不同的三档：

- **大带宽 + 限流量型**：给足 50Mbps、500Mbps 甚至 1Gbps 的峰值带宽，但每月只送 100GB 到 1TB 流量。跑完额度会被限速（雨云是限到 5Mbps），想恢复就买流量包。适合建站、API、轻量后台这类"峰值偶尔高、月总量不大"的活。
- **小带宽 + 不限流量型**：带宽只有 3Mbps 到 20Mbps，但流量不计。适合持续小流量跑着的任务，比如监控、机器人、长期在线的接口服务。
- **国际大带宽型**：带宽给到 200Mbps 到 1Gbps，价格低得离谱，但线路不对中国大陆做优化。大陆访问要绕，适合面向港澳台、东南亚或者纯海外用户的业务。

很多人买完之后觉得"这机器怎么这么慢"，八成是拿国际线路的机器去服务大陆访客，或者拿不限流量的小水管去扛一个图片站。价格没错，是档位选错了。

## 线路名听着像黑话，其实只需要看两件事

CN2 GIA、CMI、CUG、IIJ、软银——这些名词在测评站里出现频率极高，但它们只是运营商的名字缩写：

- **CN2 GIA**：中国电信的精品线路，晚高峰最稳，价格也最贵。
- **CMI**：中国移动国际，移动用户走它最舒服，香港方向延迟通常最低。
- **CUG / AS4837**：联通方向的优化线路。
- **IIJ、软银、NTT**：日本的国际运营商，香港机房接这些线路多半是为了覆盖亚太和海外，对大陆优化有限。

真正的分水岭是**去程和回程是不是都直连**。有些机器去程直连、回程绕日本，评测里的 ping 数据很漂亮，但真实下载速度并不好看。挑之前至少确认一句：三网回程是否直连。

这话说出来有点反常识，但确实存在：

- **要批量发邮件**：香港机房的 IP 基本是数据中心 IP，邮件端口限制普遍较严，投递成功率不会好。
- **要对抗大流量攻击**：香港普通套餐不带防御，需要额外买高防 IP，成本会明显上一个台阶。真的扛打，直接看裸金属或者国内高防节点。
- **要大带宽下载站**：限流量方案跑 GB 级别的分发，流量包会变成主要开支。
